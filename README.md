# Venera 漫画源合集 (All-in-One)

把多个公开仓库的 Venera / VeneraNext 漫画源整合到一个仓库地址, 同 key 取最高版本, 另含自制漫蛙源。

## 导入方法
Venera / VeneraNext → 漫画源 → 漫画源列表 → 仓库地址改为本仓库的 index.json 地址 → 刷新 → 勾选添加。

## 来源

- YHQY-Dev/venera-sources
